# PâtissPro MG — Premium & Pro

MVP offline-first de gestion pour pâtisserie à Madagascar. Ouvrir `index.html` dans un navigateur moderne. Données de démonstration locales ; elles peuvent être effacées depuis Paramètres.

## État
- Spécifications fonctionnelles V1.0 : `docs/CAHIER_DES_CHARGES_V1.0.md`
- Prototype fonctionnel MVP : `index.html` (localStorage, FR/MG, produits/recettes, stock, commandes, caisse/dépenses, exports JSON/CSV)
- Android, Cloudflare D1/Workers, AppForge, sauvegarde chiffrée/Drive et rôles multiutilisateurs : à intégrer et tester ; pas inclus comme services fonctionnels dans cette version.

## Démarrer
Ouvrir le HTML localement. Les données restent sur l'appareil / le navigateur. Utiliser Paramètres → Exporter pour la sauvegarde. Pour tester sans données de démonstration, effacer les données de démo dans Paramètres.
